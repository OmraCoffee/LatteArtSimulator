# Ómra Latte Art Simulator

A private first version of an Ómra-branded latte art practice surface built from the existing WebGL fluid simulator in this repository.

- Hold and drag on the cup to pour; works with mouse and touch.
- Select low or high pour to change the stream.
- Select Toothpick to pull a second, warm tone through the surface.
- Hold Space while dragging to keep the flow direction steady.
- Hold Shift while dragging to draw a narrow pull through the milk.
- Save Cup captures the current surface as a PNG.

Open index.html in a local static server or deploy the root as static files.
